PAINEL DE ANIVERSÁRIOS PERSISTENTE
==================================

1. No serviço onde o backend será publicado, use:
   Root Directory: backend
   Build Command: npm install
   Start Command: npm start

2. Configure estas variáveis:
   ADMIN_KEY = senha que você usará para entrar no painel
   DATABASE_URL = conexão de um PostgreSQL externo
   DATABASE_SSL = true
   DEFAULT_TIMEZONE = America/Sao_Paulo
   APP_BASE_URL = URL pública do backend

3. Abra:
   https://SUA-URL/admin

4. Para trocar de Render ou de hospedagem:
   - publique os mesmos arquivos no novo serviço;
   - use exatamente a mesma DATABASE_URL;
   - troque somente a apiBaseUrl no widget do StreamElements.

Os aniversários não ficam presos ao Render. Eles ficam no PostgreSQL externo.
O painel também tem os botões Baixar backup e Restaurar.

IMPORTANTE:
Sem DATABASE_URL, o painel funciona em modo local para teste, mas os dados podem
ser apagados pela hospedagem. O próprio painel mostra um aviso amarelo nesse caso.
